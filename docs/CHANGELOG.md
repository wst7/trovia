# 更新说明

每个版本发布时，GitHub Release 的正文直接取这里的对应小节；没有小节时退回自动生成。

## 0.14.5

- **切回「我的」页时又提示有新版本**。这个页面每次出现都会重新查一次，但它用的是安装包的版本号，绕过了「已经通过热更新拿到的版本」；于是刚提示过「已是最新」的地方，切个标签回来又变成「有新版本」。两处现在用同一套判断。
- **「新版本已下好、点这里重启」不会再变回「点这里下载」**。这个状态原本只存在内存里，页面一重挂载就丢了；现在会记下来，重挂载后仍然是重启入口，真的重启进入新版本后自动清掉。

## 0.14.4

- **清除同步密码要先确认**。原来点一下就清掉系统钥匙串里的密码，没有任何回旋余地；现在先问一句，删掉之后手机不再往网盘同步，内容仍在。
- **「测试连接」改成「保存并测试」**。它本来就会先把这一页的地址和账号存下来再测，名字却只说测试，容易让人以为不敢点。
- **没填 API Key 时，大模型那几个开关点不开**（已经打开的仍然可以关掉），下面直接说明原因。以前可以先打开、点保存，再被弹一句「请填 Key」。
- **配置区不再被「写摘要」一个开关连坐**。三个开关全关时才淡化，避免服务地址和 Key 看起来像被禁用。
- **输入框的字段名换成更深的灰**。原来用的是说明文字那一档灰，读起来像禁用状态。
- **没有语义索引时说明后果**：现在搜索只走字面匹配，点「补建索引」才会建立。
- **页面一致性**：首页的最近收藏补上了发丝线（之前它和收藏页看起来是两种列表）；设置页里没有图标的行补了占位，左边缘不再错位；同一个「没能整理」的状态在首页、收藏、我的三处统一了叫法；搜索结果的摘录里命中词也用朱红标出来，和标题一致。
- **AI 问答页没带问题时不再是一片空白**，会说明怎么用并给一个回首页的入口；返回按钮也统一成了其它页的「‹」。
- **诊断页改名「诊断信息」**（原来叫「崩溃记录」，但主体是操作日志），日志改成等宽字体，环境里的 `sync_base` 改成 `sync_base_rows`，免得被当成第二个文档数。
- **收藏页的筛选收成一行**：「没能整理」和「只看导入的」从两行裸文字变成两个带状态的胶囊按钮，「重试全部」留在同一行右侧，首屏少了三行控件。
- **首页搜索每次只跑一次**。它原本在按钮里跑一遍、又在数据变化时跑一遍，诊断日志里每个查询都有两条记录、耗时翻倍。
- **搜索框旁的开关现在两个模式都写着**「搜索 / AI」，不再是单独一个词让人猜。
- **图片上认出来的字只用于搜索，不再进入正文**。它原本被并进了纯文本，于是既会被当作正文的兜底显示出来，也会被拿去写摘要和关键词——截图里的一行字可能变成这一篇的摘要。现在这些字只进检索串。已经存下的旧条目要重新整理一次才会干净。

## 0.14.3

- **连续点「新版本」不会再各下一次**。设备日志显示 43 秒内点了四次，每次都重新开始一遍几十兆的下载，而且都写进同一个临时文件。现在下载或安装进行中，再点不会有任何动作。
- **更新过程开始留痕**。以前日志里只有「检查更新」，下载、安装、热更新各自的结果都不记录，出问题只能靠猜。现在这几步都会写一条记录。
- **设置页不再一手画圆点一手画箭头**。外观和语言每行原本左边是单选圆点、右边是「›」，一个说点了就地生效，一个说点了会进入下一页。现在圆点在右侧、没有箭头；顺带把「新版本」的向上箭头从朱红改成中性灰，红色只留给「清空全部收藏」这类不可逆操作。

## 0.14.2

- **同一个版本不再要求下载两遍**。热更新换的是 JS，不改安装包的版本号，所以更新完之后界面仍然认为「有新版本」，接着又让你下几十兆的完整包。现在会记住已经通过热更新拿到的版本，同一个版本不再重复提示；下一个版本照常提示。
- **「新版本」的提示改回说事**。原来的提示写着「点这里下载」，但它没有可点的按钮，点了没反应；现在改成「有新版本 v0.14.2 · 大小」，只有行本身才可点。
- **下载一开始不再显示「0%」**。首字节到达前显示「准备下载…」，避免看起来卡死。

## 0.14.1

- **修好了详情页正文里的 `](https://…)` 残片**。GitHub 这类页面的徽章是「图片套在链接里」，渲染器为了让每张图独占一段，会把图片换成带空行的形式——结果把链接从中间撕开，露出了半截语法。现在徽章先降级成文字链接，再处理独立图片。

## 0.14.0

- **收藏页改成左轨列表**：日期收进左侧一条竖轨，不再当分组标题反复出现；竖线把整列连成一条，动线只走一个方向。没能整理的条目，那段竖线变成 2px 红色，扫一眼就知道哪条要处理，而不是角落里一个小圆点。
- **搜索结果先给证据**：「字面命中 / 意思相近」排在标题之上，紧跟命中的那句原文，最后才是命中说明。判断「是不是这一篇」靠的是证据，不是标题像不像。
- **详情页摘要在前、长文默认收起**：摘要改成下沉底色整块，朱红只留给「打开原文」这一个动作；正文超过一千二百字时先给三行纯文本预览和「展开原文」，短文不折。
- **浏览器插件可以装了**：补了图标、可加载的 zip 打包与说明文档，WebDAV 客户端加了端到端测试（建目录、写入、读回、同链接重存覆盖同一文件）。
- **代码注释统一成英文**：全仓约一千九百行注释与 Python docstring 改为英文，`npm run lint:comments` 守住这条线；界面文案仍在 i18n 字典里，中文用户看到的字一个没变。

## 0.13.9

- **字体回到手机默认字体**：随包带的思源宋体撤掉了。它的字面比系统字体大一号，在固定行高的地方会顶出去——首页大标题就压在输入框上，输入框里的占位文字和「搜索」也叠在一块。现在全 app 用系统字体，布局回到设计时的尺寸。
- **开发者模式的说明改成说事**：不再写「出问题时发给我」，改成「记录操作日志，排查问题时用」。
- **同步说明去掉「我们」**：这个 App 没有账号也没有服务器，文案里不再出现「不经过我们的服务器」。

## 0.13.8

- **可以主动检查更新**：点「我的 → 版本」那一行就会现查一次（不走十分钟缓存），有新版立即开始下载，没有就明确说「已是最新」。
- **操作日志看得清**：开发者模式下的日志改成最新在上，标题写明「操作日志」；环境快照里多一行日志状态（多少字节、几行、开发者模式开没开），空日志时能立刻判断是没记录还是读不到。
- **更新检查也进日志**：每次检查记一条 `op.update.check`，带当前版本、最新版本和是不是手动点的。

## 0.13.7

- **全 app 一套字体**：列表、设置、搜索、按钮、输入框、底部导航全部改用随包带的思源宋体，屏幕上不再一半黑体一半宋体；只有日志用等宽。
- **落地页只讲功能**：删掉「端侧 OCR」「本地索引」「热更新」「scripts/probe-extract.mts」这类实现说明，读不到正文的站点直接写结论。
- **版本号那行不再过期**：更新检查结果缓存十分钟，发版后不会继续挂着上一版；查不到时退回上次结果，而不是显示「暂时查不到」。
- **操作日志**：开发者模式下记录保存、抓取、搜索、同步、删除的每一步和耗时，出问题可以直接把日志发出来。

## 0.13.6

- **列表回到表格**：收藏页每一行的底色改成和页面一致，组内只留一条发丝线，不再是浮在纸面上的一张张白卡片。
- **全 app 一套字体**：界面文字统一走黑体并显式指定字族，不再跟着厂商皮肤变；阅读区（标题、正文、小标题）仍是思源宋体，元信息是黑体。
- **提示只说一次**：36 条文案改短，去掉「本机」「解析队列」这类实现细节，也去掉「你可以稍后重试」这类客套；一句说清发生了什么、下一步做什么。
- **别的设备的链接不再空白**：从浏览器插件或另一台设备同步进来的条目只有链接和标题，以前会被当成「已整理完」的空条目留在列表里，现在会进队列自动抓正文；同一个链接也不会再出现两条。

## 0.13.5

- **正文换成宋体**：随包带一份思源宋体子集（常用 7542 字，2.3MB），正文 17px / 行高 31；标题仍是黑体，层级靠字形而不是粗细区分。生僻字回落到系统字体，不会缺字。
- **更新不再偷偷下载**：检查到新版本只在版本号旁边点一个小箭头，点一下才开始下载；热更新下完提示「点这里重启生效」，整包下完交给系统安装器。
- **同步丢条目修好**：云端 7 份、本地 6 份却提示「没有可同步的」——etag 记着但基准 rev 丢了时，那条永远拉不回来；现在两者都在才跳过，并且报告会说「云端有 N 份读不出来」。
- **清空日志连崩溃记录一起清**。

## 0.13.4

- **修好「分享链接保存失败」**：升级上来的库缺 `imported_at` 列，导致每次保存都报错。补列改成清单式迁移，并加了一条真跑 SQL 的回归测试。
- **X / Reddit 链接能读了**：X 走官方 syndication / oembed 接口取正文与时间；Reddit 非登录只给外壳，现在会明确标成「站点没让读正文」，不再存一段空白。
- **更新入口并进版本行**：设置里的版本号一行直接显示「新版本 vX · 大小 · 点这里下载」，不再单开一页、也不再区分整包与热更新两种下载。
- **开发者模式**：设置 → 关于 → 开发者模式，默认关；开启后出现「查看日志」，可把环境、崩溃记录与保存日志一次性分享出来。
- **大库同步修好**：云端超过 500 个文件时，第 501 个之后永远同步不到；现在扫全部条目，用 etag 跳过没变过的文件。

## 0.13.3

- **版本号读原生版本**：装的是哪个 APK 就显示哪个，热更新不会再把界面上的版本号带偏（之前装 0.13.2 会显示 0.12.2）。
- **分享失败说得具体**：不再一律「保存失败，请稍后重试」，改成区分数据库占用、存储写不进去、数据库损坏、重复收藏四种原因，并给一句能行动的话。
